# 猜你想做：实机验收记录

这份记录用于关闭自动测试无法证明的系统边界。测试使用专门的系统账号、合成消息和测试项目，不授权读取日常聊天或本机编码历史。每个平台分别填写；留空代表未验证。

安装包忽略 `MEMO_TEST_USER_DATA`，因此安装、升级、卸载要在独立测试账号或虚拟机中完成。开发构建可用以下方式隔离工作区；不要用 `start:real` 代替，它刻意不继承测试目录。

macOS/Linux：

```sh
pnpm build
MEMO_TEST_USER_DATA="$(mktemp -d "${TMPDIR:-/tmp}/bugu-acceptance.XXXXXX")" pnpm --filter @memo/desktop exec electron out/main/index.js --mode=real
```

Windows PowerShell：

```powershell
pnpm build
$env:MEMO_TEST_USER_DATA = Join-Path $env:TEMP ("bugu-acceptance-" + [guid]::NewGuid())
New-Item -ItemType Directory -Path $env:MEMO_TEST_USER_DATA | Out-Null
pnpm --filter @memo/desktop exec electron out/main/index.js --mode=real
Remove-Item Env:MEMO_TEST_USER_DATA
```

## 用例

逐项保存结果和截图/录像编号。不要把下面的期望当作已通过的结论。

| ID | 操作 | 应当看到 | 实际结果/证据 |
| --- | --- | --- | --- |
| M01 | 新账号安装并第一次打开 | 空任务工作区；事件学习默认关闭；不自动请求观察许可 | |
| M02 | 开启学习但拒绝系统观察权限 | 授权范围与降级状态可见；不弹主动提示、不占 Tab；手动入口可用 | |
| M03 | 只授权测试来源；用五件不同的合成工作事件作真实选择 | 同一件事重复切换不能填充门槛；足够独立选择后才主动推荐 | |
| M04 | 保持源应用前台，主窗口最小化且桌宠关闭 | 左上角独立提示；源应用仍持有输入焦点；默认 3 秒边框计时后退场 | |
| M05 | 在英文布局持续打字；暂停输入；提示出现后再次输入 | 打字时不弹、不占键；暂停并重验后给足计时；恢复输入先释放键位 | |
| M06 | 使用中文拼音、日文或韩文组合输入，未完成候选选择 | 不抢 Tab；在无法可靠判断组合结束的平台暂停主动提示；手动入口仍可使用 | |
| M07 | 提示内按一次 Tab，并尝试长按或重复按；倒计时结束后再按 | 一次有效确认至多发出一次打开请求；到期后 Tab 恢复源应用功能 | |
| M08 | 改组合键、占用冲突键、设为 click | 配置与键帽一致；冲突明确反馈；click 不注册确认键 | |
| M09 | 提示出现时切换窗口、锁屏/解锁、睡眠/恢复、拔掉副屏 | 旧提示失效；无离屏残留；不把旧窗口对象当成新对象 | |
| M10 | 系统设置撤销观察权限；随后重新授权并重新开启观察 | 旧提示与租约释放；不会自行反复弹权限；明确重新启用后恢复 | |
| M11 | 正在识别/推荐时撤销来源；或主动结束 helper 进程 | 迟到结果不写入；helper 至多有限重试；键位不残留；手动入口可用 | |
| M12 | Chrome/Edge 独立 profile 中授权已有测试网页；切后台；重启 BUGU；撤权后重启浏览器 | 无需刷新即可生效；只前台对象有效；重连恢复；撤权持久，查询参数不进入诊断 | |
| M13 | 推荐错工具/错事项/错具体对象，分别反馈，再撤销反馈 | 三种错误作用范围不同；忽略不扣分；执行失败不制造真实选择 | |
| M14 | 新项目选择不同工具；删除该项目的学习记录 | 项目特例在证据足够后优先；具体对象不跨项目；清除后不恢复已删除贡献 | |
| M15 | 清除学习数据、重启、导出诊断 | 学习关闭、计数清零；工作事项保留；诊断无原文、窗口标题、路径或按键 | |
| M16 | 同意的受试者进行 30 次工作流对照 | 记录推荐/弃答、真实目标结果、误跳转、手动操作数与耗时；不能只统计点击率 | |

Windows 10 与 11 均使用标准用户，并补测管理员/受保护窗口：无法读取时不伪装为已识别。Linux 分别测试 X11/Wayland，受限能力应与文案一致。macOS 至少覆盖 arm64/x64 的安装及权限路径。

## 通过标准与留档

- 每个声明支持的平台有实际结果；Actions 上 Windows Server 的构建和协议检查不替代 M05–M11。
- 保存失败、弃答和不能确认目标的结果，不把系统接受打开请求当成具体会话已打开。
- 24 小时报告需 `outcome=passed` 且采样连续，不能把电脑睡眠的时间算作持续观察；模型/启动夹具的结果不能代替真实 helper 资源报告。
- 商店安装链接、公开隐私政策、签名/公证与安装包校验记录另行附上。缺失时保持整项待验收，不关闭 Issue #158。
