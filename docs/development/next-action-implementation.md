# 猜你想做：实现与验证记录

对应 [完整方案](../product/BUGU_猜你想做_完整实现方案.md)、Issue #158、PR #159。

## 用户流程

入口已接入普通启动和正式构建，默认关闭、无演示数据。设置 → 猜你想做 → 开启学习 → 勾选已有连接并确认交给当前分析模型。系统观察另外开启，操作系统许可另外申请。右上角「猜你想做」可打开授权记录、选择处理工具、查看最近建议和纠错；桌宠无需开启。

真实链路是：来源授权 → 可见对象/主动打开记录 → 真实模型分类 → 用户选择或有双边引用的模型归因 → 事件分组学习 → 模型从可信候选中推荐 → 短提示/最近建议 → 主机重新核验目标并打开。同步消息、停留时长、窗口切换本身都不能建立关联。

### 能力边界

- macOS：Swift 前台和 AX 观察、临时输入活动、短时 Tab event tap；AX 只在选定应用内，将可见静态文本与既有授权记录做完整匹配，本机匹配后只返回记录 ID。重复/太短/不可见/无法匹配的记录不识别。需要实际辅助功能与输入监控许可。
- Windows：C++ 前台进程、UI Automation 静态文本匹配、低级键盘 hook 临时租约；不注入目标进程、不保存按键值。受保护/不可访问窗口不识别。IMM/中日韩键盘布局无法可靠判断跨进程组合状态时暂停主动提示与 Tab，仍可使用手动入口。
- Linux X11：原生前台观察；通用 XIM 组合状态不可可靠确认，不接管 Tab，不自动弹快捷键提示，使用浏览器授权对象与 BUGU 内的最近建议/点击操作。
- Wayland：明确受限模式，不声称有跨应用输入观察能力。
- 中日韩输入法组合状态无法确认时保持保守，不以“等够时间”假装组合已结束。系统观察不可用时不主动弹窗；手动入口可继续使用。
- 浏览器 URL 目前精确识别已授权 GitHub 仓库 PR。飞书加密消息链接不能逆推出 message ID，未做猜测匹配；飞书桌面可走限定 AX/UIA 或在 BUGU 内主动打开授权消息。
- 浏览器扩展提供可加载包与本机注册；Chrome/Edge 商店发布、签名和组织策略分发不是已完成事项。
- 所有启动反馈区分“已发出打开请求”与“确认打开具体对象”。现有系统启动 API 只能证明 dispatched，不冒称 target-confirmed。

最近事件、选择与纠错支持 7/14/30 天；无正文的习惯贡献支持不额外保留或 30/60/90 天，最多 5000 条。贡献仅保存事件类型、选择和可撤销引用，活跃事件优先且不重复计数。事件最多 5000，选择/反馈各 20000。缩短期限立即生效，延长不恢复删除的数据。撤销来源、目的地依据、授权版本变化、原文撤回、删除项目/应用或全部清除均移除相关贡献。

配对秘密使用 macOS Keychain、Windows 用户级 DPAPI、Linux Secret Service；配置中只放引用或用户密文。旧开发版明文配对升级后不再保留，安全存储失败则停连接。停用操作先断连接并轮换秘密，即使钥匙串锁定也删除配对配置，不会继续接受旧令牌。原生帧与确认响应有协议版本，浏览器去掉查询参数与片段；切标签、撤销站点权限会清空对象，迟到的识别结果不能恢复旧对象。

## 稳定性与审查

10 分钟隔离 Electron 持续读取通过（600.6 秒、60 次采样）：读取耗时 47–87 ms，模型调用保持 7 次、窗口保持 1 个；整个 Electron 进程树 RSS 从约 664 MiB 到 606 MiB，采样峰值约 685 MiB。该数字包含整个应用，不能视作本功能新增内存。模型和启动动作为夹具，不申请系统观察权限；不能替代 24 小时、真实 helper 和各系统桌面验收。`BUGU_NEXT_SOAK_SECONDS=86400` 可运行完整时长。

按 code-review-expert 的安全、竞态和数据一致性检查表审查：修复系统密钥删除失败时撤权不完整、异步 socket 清理误删新 socket、安装/移除并发、切标签后旧识别结果回写、站点撤权不清上下文、页面重新可见/主程序重启后不重试。相应回归使用隔离目录、伪造浏览器 API 和合成数据。原生密钥测试仅创建并删除测试自己的随机项。
