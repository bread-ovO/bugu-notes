当前有意采取保守保留策略：事件与依赖选择最多保留 30 天；事件上限 5000，选择/反馈分别最多 20000。超限和过期删除会级联移除依赖，再从剩余事实计算偏好。尚未引入独立的 90 天去标识贡献层，不会谎称有 90 天学习历史。

模型归因必须同时验证源与目标授权，再发送文本；保存的是依据 ID、版本、来源和对象引用，不把引用原文复制进学习表。可信 core 适配器才可录入观测和授予本功能权限；renderer 只能读设置、修改设置、反馈、撤销和清除，不能伪造“看过消息”或注册可执行目标。适配器的实际授权接入完成之前，正式入口保持关闭。

## 内部预览与验证

```sh
npx --yes pnpm@10.34.5 build
# 仅开发 Electron 支持该参数；打包应用会忽略它。
MEMO_TEST_USER_DATA="$(mktemp -d /tmp/bugu-next-preview.XXXXXX)" npx --yes pnpm@10.34.5 --filter @memo/desktop exec electron out/main/index.js --bugu-next-action-preview

npx --yes pnpm@10.34.5 test:next-action
npx --yes pnpm@10.34.5 test:storage next-action-integration
npx --yes pnpm@10.34.5 test:next-action:e2e
npx --yes pnpm@10.34.5 typecheck
npx --yes pnpm@10.34.5 check:boundaries
```

内部预览仅显示设置，不制造学习记录或自动弹演示建议。E2E 独立 host 用虚构事件与登记的空操作验证弹窗；不读取本机聊天/编码历史、申请辅助功能权限或实际跳到其他应用。

默认 Tab 尚未接入原生实现，窗口宿主明确拒绝展示 Tab 提示；不会用 `globalShortcut('Tab')` 或要求先聚焦弹窗冒充支持。自定义组合键也只有输入状态已知、IME 未组合且 OS 注册成功时才显示键帽。缺少这些信号时不占键。

测试截图位于 `test-results/next-action-hint.png`、`test-results/next-action-settings-narrow.png`。它们仅用于本地验收，不作为用户真实行为或推荐准确率证明。

## 本次验证结果

- 72 个定向单元测试通过（71 个新增领域/模型/提示用例，以及扩展的模型宿主回归）。
- 6 个新增 Electron E2E 用例与 1 个现有主窗口/核心/模型设置回归通过；仅运行受影响用例，没有运行全套 E2E。
- 8 组 SQLite/核心集成通过：next-action、task-chat、task-model、task-structure、reference-audit、revision-review、source-import、feishu。
- TypeScript、包边界检查和桌面 build 通过。
- macOS arm64 `package:dir` 构建通过；未签名，未发布，不代表 Windows/Linux 或正式签名验收通过。

E2E 使用真实 Electron 窗口与隔离数据库验证桥接、重启、纠错/撤销/清除、失效确认、非激活展示和倒计时；模型与外部应用打开使用可控测试适配器。因此这些结果是功能确定性测试，不是模型推荐正确率、真实客户端兼容性或原生 Tab 输入验收。
