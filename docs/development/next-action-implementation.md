# 猜你想做：实现与验证记录

对应 [完整方案](../product/BUGU_猜你想做_完整实现方案.md)、Issue #158、PR #159。

## 用户流程

入口已接入普通启动和正式构建，默认关闭、无演示数据。设置 → 猜你想做 → 开启学习 → 勾选已有连接并确认交给当前分析模型。系统观察另外开启，操作系统许可另外申请。右上角「猜你想做」可打开授权记录、选择处理工具、查看最近建议和纠错；桌宠无需开启。

真实链路是：来源授权 → 可见对象/主动打开记录 → 真实模型分类 → 用户选择或有双边引用的模型归因 → 事件分组学习 → 模型从可信候选中推荐 → 短提示/最近建议 → 主机重新核验目标并打开。同步消息、停留时长、窗口切换本身都不能建立关联。

### 能力边界

- macOS：Swift 前台和 AX 观察、临时输入活动、短时 Tab event tap；AX 只在选定应用内，将可见静态文本与既有授权记录做完整匹配，本机匹配后只返回记录 ID。重复/太短/不可见/无法匹配的记录不识别。需要实际辅助功能与输入监控许可。
- Windows：C++ 前台进程、UI Automation 静态文本匹配、低级键盘 hook 临时租约；不注入目标进程、不保存按键值。受保护/不可访问窗口不识别。
- Linux X11：原生前台观察；通用 XIM 组合状态不可可靠确认，不接管 Tab，不自动弹快捷键提示，使用浏览器授权对象与 BUGU 内的最近建议/点击操作。
- Wayland：明确受限模式，不声称有跨应用输入观察能力。
- 中日韩输入法组合状态无法确认时保持保守，不以“等够时间”假装组合已结束。系统观察不可用时不主动弹窗；手动入口可继续使用。
- 浏览器 URL 目前精确识别已授权 GitHub 仓库 PR。飞书加密消息链接不能逆推出 message ID，未做猜测匹配；飞书桌面可走限定 AX/UIA 或在 BUGU 内主动打开授权消息。
- 浏览器扩展提供可加载包与本机注册；Chrome/Edge 商店发布、签名和组织策略分发不是已完成事项。
- 所有启动反馈区分“已发出打开请求”与“确认打开具体对象”。现有系统启动 API 只能证明 dispatched，不冒称 target-confirmed。

事件、选择及纠错最多保留 30 天，事件 5000，选择/反馈各 20000。当前没有独立的 90 天去标识贡献层。删除来源或项目会重建剩余事实的偏好；不会保留被撤销来源的贡献。

## 验证方法

```sh
npx --yes pnpm@10.34.5 build
npx --yes pnpm@10.34.5 test:next-action
npx --yes pnpm@10.34.5 test:storage next-action-integration next-workflow-integration
npx --yes pnpm@10.34.5 test:next-action:e2e
npx --yes pnpm@10.34.5 test:next-action:native
npx --yes pnpm@10.34.5 typecheck
npx --yes pnpm@10.34.5 check:boundaries
npx --yes pnpm@10.34.5 package:dir

# 合成数据，真实模型；不会读取真实聊天、编码历史或登录文件。
npx --yes pnpm@10.34.5 eval:next-action --live --provider codex-cli --limit 9
# 完整 360 行测试集包含时间/候选排序相关变体，不是 360 个独立语义样本。
npx --yes pnpm@10.34.5 eval:next-action --live --provider responses --model MODEL --base-url URL --limit 360
# API 密钥由调用者通过 BUGU_EVAL_API_KEY 环境变量提供，不保存到报告。
```

确定性 E2E 使用真实 renderer/preload/runtime/utility core/SQLite，只有模型传输与操作系统启动动作替换为隔离夹具。原生协议测试使用隔离目录和虚构消息，不申请系统权限、不观察真实用户数据。原生 Tab 的 E2E 测租约接口与完整窗口状态机，不冒充真实键盘 hook 实机认证。

97 个定向单元测试已通过。9 组相关数据库/核心集成逐项验证；新增 UI 和原生适配后的最后一轮 E2E、打包与三平台编译结果在本次 PR 验证区记录。不会将通过替身测试记为真实模型准确率。

真实 Codex 冒烟测出了提供商不接受 `uniqueItems` 的问题：已拆分传输 Schema 和本地验证 Schema，传输兼容而本地仍拒绝重复目标。修复后的真实评测结果单独记录，不掩盖首次失败。

## 仍需保留的发布门槛

真实 macOS/Windows 10/11 权限撤回、输入法、多屏、受保护窗口、24 小时资源曲线；完整真实模型锁定集指标；Chrome/Edge 商店分发/签名；未覆盖客户端的具体对象入口。这些需要实机/账号/发行条件，不能用接口或编译成功标成完成。当前 PR 不关闭 Issue #158，不发布新 tag。
