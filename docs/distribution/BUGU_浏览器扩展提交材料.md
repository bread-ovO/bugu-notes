## 商店文案

名称：BUGU 不咕 · 事件桥接

简短说明：把正在查看的工作对象关联到 BUGU，学习你处理不同事情时常用的工具。

详细说明：

BUGU 帮你从分散的工作上下文中整理事项。事件桥接扩展只在你授权的网站里，识别当前前台页面的对象网址，并交给这台电脑上的 BUGU。网页正文、Cookie、浏览历史和输入内容不会由扩展读取或发送。网址的查询参数和片段会移除。

桌面端仍须单独授权相应来源并启用事件学习。能够匹配到已授权记录后，BUGU 才使用你选择的模型理解事件，结合真实选择给出下一步建议。未匹配的页面不会被用来学习，也不会自动打开应用、发送消息或修改任务。

目前网页对象精确匹配支持 GitHub 仓库 PR。飞书加密链接不能可靠还原消息身份，不能承诺所有飞书网页均可识别。飞书消息可通过桌面客户端的受限观察或 BUGU 内主动打开已授权记录使用。

## 隐私政策正文草案

本扩展仅处理前台、活动、已授权页面的网址，去掉查询参数和片段后传给本机 BUGU。扩展不采集页面正文、Cookie、完整浏览历史、键入内容或截图，不包含广告或分析 SDK。

本机 BUGU 会将对象标识与现有、另行授权的来源记录匹配。用户启用事件学习并同意模型用途后，相关原文片段可能发送给用户所配置的模型服务；该服务的隐私条款由提供商决定。本扩展本身不持有模型 API 密钥。

原始观察状态只存在于内存；最近业务记录默认保留 30 天，可缩短。内容之外的习惯贡献最多保留 90 天，可关闭额外保留。贡献仅包含类型、选择和可撤销引用，不复制消息正文。用户可撤销网站或桌面来源授权，按来源/项目/应用或全部清除学习记录。

浏览器桥接的配对秘密由 macOS Keychain、Windows 用户级 DPAPI 或 Linux Secret Service 保护。安全存储不可用时不建立持久配对。停用桥接会删除注册和密钥引用，并使旧连接失效。
