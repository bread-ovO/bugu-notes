# 猜你想做

它学习的是“遇到什么事，你选择什么工具”，不以停留时间判断你在做什么，也不会替你完成事项。

## 开始使用

1. 在连接页授权需要使用的工作来源，在设置中配置 AI 模型。
2. 打开「设置 → 猜你想做」，开启事件学习，勾选学习来源并确认模型使用范围。
3. 如需跨应用提示，另行开启指定应用观察，并授予系统提示的权限。不开观察，也可以从右上角「猜你想做」打开已授权记录并选择工具。
4. 同类事情先积累至少五次可靠、独立的真实选择。重复打开同一件事和点击推荐不会制造新样本；模型归因的弱证据需要更多样本。
5. 浏览器扩展需另行授权站点；授权后已打开的网页即可开始识别，无需刷新。主程序重启后会重新建立连接，撤销站点许可后停止识别。

## 收到建议

提示独立显示在工作区左上角，默认 3 秒，不需要桌宠。默认 Tab，可在设置中改为组合键或 `click`（仅点击）。输入中或组合状态不明确时暂停提示；消失后可从右上角查看最近建议。

只有可靠入口才会定位到具体对象。否则会明确写“打开应用”。看到“已发出打开请求”不代表已经确认某个具体会话打开成功。

## 推荐错了

在最近建议里区分“这次不对”“事情理解错了”“目标不对”。可以修正类型、指定此类事件的工具偏好，并撤销反馈。忽略或超时不会给工具扣分。

新项目最初会沿用已有的通用工具偏好。如果该项目的做法不同，可以直接指定项目内偏好；也可以关闭“跨项目使用工具偏好”。持续出现相反的真实选择时，系统会先暂停不可靠的推荐，再学习项目特例。

## 保留和清除

「设置 → 猜你想做 → 保留与清理」可以设置最近记录为 7、14 或 30 天；习惯贡献为不额外保留、30、60 或 90 天。保存后缩短立即生效，延长不会恢复已经删除的数据。贡献没有消息正文，只保留计算偏好及撤销所需的引用。

清除学习记录会关闭功能并删除记录、贡献、授权范围和偏好，不删除你的工作事项与连接原文。撤销来源或删除项目也会移除相关贡献。

## 当前支持范围

| 环境 | 能力与限制 |
| --- | --- |
| macOS | 已编译 arm64/x64；观察需要辅助功能与输入监控许可。非 ASCII 输入法无法可靠确认组合结束时暂停提示，手动入口仍可使用 |
| Windows | 已编译 x64；UIA 不读取受保护窗口。检测到 IME/中日韩布局时保守暂停提示和 Tab，手动入口仍可使用 |
| Linux X11 | 支持前台身份；不声称可靠判断所有输入法，不接管 Tab，使用手动建议入口 |
| Wayland | 受限模式，不声称有跨应用输入观察能力 |
| 浏览器 | 开发包支持 Chrome/Edge，精确识别已授权 GitHub PR；正式商店分发尚待完成 |

这些是实现范围，不能代替所有系统版本与输入法的实机验收。出错时可从设置导出诊断，文件只包含平台、能力、计数及错误码，不含原文、路径、账号、窗口标题或按键。
